# Computer and robot vision notes and labs

In this repository you will find my notes for the computer and robot vision course @ university of Milan Bicocca A.Y. 2026/2027.

The notes are written in typst and are free to modify and use for educational purposes.
The content of the notes is mainly based on the book "Computer Vision:
Three-dimensional Reconstruction Techniques" by Andrea Fusiello, and some other sources.


You can also find in 
the labs folder the code for the labs that I have done during the course. The code is in python and includes the assets used for the labs.
